# Implemented Plan Archive

This folder holds completed implementation plans, executed procedures, and
post-review plan records that are no longer active work queues.

Use these files as audit history only. Current implementation authority lives in
`docs/features/FEAT-*.md`, `docs/TRACEABILITY.md`, and the maintained runtime
contracts. Current backlog ordering lives in `docs/features/README.md` and
`docs/next_steps.md`.

Keep live evidence/results that are still cited for verification near the active
docs unless they are only an executed procedure.
